# 猫咪原稿补色资源

共六列、三种原始表情，按 `cat-{pet}-{expr}.png` / `.svg` 使用。两种格式都包含真实透明背景；SVG 仅嵌入对应 PNG，不是重绘矢量线稿。所有文件使用 288×288 画布、276px 脚底基线，切换表情不会改变布局尺寸。

| pet | 名字 | 用户命名 |
| --- | --- | --- |
| 0 | 辣椒 | 三花猫 |
| 1 | 奶球 | 白猫 |
| 2 | 煤球 | 黑猫 |
| 3 | 芝麻 | 奶牛猫 |
| 4 | 布丁 | 暹罗猫 |
| 5 | 团子 | 橘猫 |

`expr` 0、1、2 对应原稿第一、二、三排。布丁保留原稿第五列的灰白斑点配色，没有根据品种名重设计或交换列。

来源：用户提供的 `101f571ef9b19c763e3b7b6ed326d62e.png`；原文件逐字节归档为 `sources/original-user.png`。`original-atlas.png` 只是裁掉透明边距的原稿；带 `white-preview` 的文件仅用于辨认透明底上的黑线，不作为线上资源。

补色：2026-10-18 使用内置 `image_gen` 图像编辑工具，以用户原稿为编辑目标、既有 `assets/pets-v2/dog-0-0.png` 为暖色风格参考，一次生成 `atlas.png`。完整提示词在 `sources/coloring-prompt.txt`。原始轮廓、眉眼鼻和表情按原稿保留；生成式补色无法承诺每个线条像素完全相同。

`scripts/prepare-cat-art.cjs` 只做连通区域切分、对齐和必要的封闭透明洞保护，不创建或替换图案。`manifest.json` 记录切分边界、透明修复像素数与 SHA-256；`preview.png` 为18帧透明总览，`preview-cream.png` 是浅奶油背景检查图，仅用于预览。验证入口是 `tests/cat-art.cjs`。
