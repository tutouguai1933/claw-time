# 小屋图层素材

使用内置 `image_gen` 生成，无安装依赖、无 API/CLI 回退。运行时只允许更换后方猫爬架、左侧猫爬架和右侧沙发，共九张带真实 alpha 的家具 PNG；中间软垫固定使用原图，保持原位置。

- `room-T-W.png`：T 为早/中/晚（0/1/2），W 为晴/雨/雪（0/1/2）。每张分别从对应 `assets/scenes/original-room-T-W.png` 编辑，去除家具及家具投影，保留墙窗、地毯、地板和对应天空天气。生成式编辑会有轻微细节差异，不是逐像素复刻。
- `left-0..2.png`：原木方屋、拱门小窝、尖顶小屋。
- `back-0..2.png`：皇冠高台、拱桥双塔、叶片猫树。
- `sofa-0..2.png`：懒人豆袋、云朵软垫、环抱软座。
- `pad-0..2.png`、`pad-floor-repair.png`：仅保留的历史素材，运行时不读取、不展示、不用于替换或移动原软垫。旧花垫另存于 `archive-cushion-v4/pad-1-flower.png`；相关生成记录 `generation-cushion-v4.json` 仅供溯源。

进入小屋默认保留原型布置。仅后架、小猫架、沙发三处有更换虚框，可分别恢复原型或恢复整屋；原软垫没有编辑入口。读取旧存档时删除 `pad` 替换标记和款式，保留其余家具及装饰。后架按比例适配；小猫架按原图 0–36% × 40–73% 的占位定标，在三款的长腿之间复用各自原有木质台面像素，添加 y=65.41% 的下层平台，原有脚底、腿、梯子和整体轮廓不变；沙发限于 73–100% × 52–85%，左侧对齐并裁出侧面，向画面外延伸。具体参数见 `manifest.json`。运动可从 `HouseEditor.getLayout('left')` 读取当前平台、梯子及脚底的世界坐标；传第二参数 0–2 可读取指定款式；固定软垫的 `getLayout('pad')` 返回 `null`。

后架、软垫和局部修复背景的提示词与来源记于 `final-prompts.json`。最新小猫架/沙发采用 `generation-original-view-v3.json`，分帧说明见 `original-view-v3-packing.json`，旧版备份于 `archive-v2/`。家具原始图集位于 `sheets/`。

运行时背景始终以原型的无水印副本 `assets/scene-clean/room.png` 为统一几何底层，只在已替换家具的占用区域使用 `room-1-0.png` 清理层。九种天气/时间均保留家具、窗框和完整地板/地毯的位置和形状。窗玻璃区域按对应原型裁入真实窗景，包括原始雨线、雪花和窗底积雪；前景平台和窗框始终保留canonical像素，早/晚雪源图中误落在室内猫架顶的雪帽以相邻同曝光窗景消除。其余 `room-T-W.png` 作为原生成素材保留，不用于运行时切换几何。原始场景的 SHA256 记录在 `assets/scenes/original-checksums.json`。

软垫及左梯子按轮廓遮挡，后猫架清理区域下界止于67%，避免旧梯子/墙面碎片和地毯矩形接缝。晴雨雪夜晚均参考最初夜景的明确暖黄受光面，在现有上窗框内侧绘制窄灯源，配合清晰有边界的地毯/地板光束与原猫架朝光面。没有低分辨率模糊光场、径向光池或雾状亮层。家具被替换后，其原受光面同步失效，避免旧平台形状留在新背景上。首页、编辑器、总览和PNG导出使用同一合成规则。

软垫及其椭圆投影始终使用 `assets/scene-clean/room.png` 的原始像素和原始位置，不再移位、修补其底图或读取替换软垫；即使旧存档或直接合成请求带有 `pad` 款式也会忽略。替换其他家具时按原垫轮廓保护其前景遮挡。首页、编辑器、天气和PNG导出共用该规则。源图及无水印底图文件均未修改。

打包使用浏览器原生 Canvas 按三列切分，以 alpha 连通主体确定紧边界，保留约三像素透明边距与抗锯齿，清理与主体分离的生成碎屑；没有用白底替换透明区域。`manifest.json` 记录最终尺寸、原图边界及透明像素检查。
