# 九种窗景与局部缺陷修复

`afternoon-source.png` 使用内置 imagegen 编辑原 `assets/scene-clean/room.png`，作为去除玻璃内三条平台和补齐云角的同画风参考。没有覆盖原图。生成输入、要求见 `prompt.txt`；图片已复制进项目，直接打开HTML不依赖生成工具目录。

主场景仍以原图为家具、软垫和地板来源。中午晴天只修改750×1400坐标下四处玻璃范围：`[384,390,45,100]`、`[384,545,146,77]`、`[384,693,146,80]`、`[565,597,15,56]`，其他像素保持原样。范围覆盖完整台面边、细线和雪帽，不只处理台面中央。

早/中/晚与晴/雨/雪共用同一云朵形状；窗玻璃以平面颜色和原生Canvas雨线/雪花表示天气，雪天在窗底保留积雪。早晨奶油暖色与柔光，中午明亮原稿日照，夜间深蓝窗外、明确暖灯和受光平面。家具形状和位置不随天气变化。未使用模糊光池、发光雾或3D效果。

原沙发恢复蒙版按可见轮廓裁切，避免用矩形把旧沙发及旧窗景重新覆盖到云上。相同合成入口用于主页、装扮、总览和PNG导出。所有原始场景、前版素材与散列保留。

验证：`tests/window-scene-repair.cjs`逐个检查九种状态的三条台面完整范围、云角、玻璃修复范围外零改动、替换后云区无旧绿色沙发，以及首页/总览同步；`tests/weather-flat-reference.cjs`检查九种状态区别、夜灯、暖色受光、雨线与窗底积雪。离线图片载入缓存由已有`build-scene-cache.cjs`生成，不安装依赖。
