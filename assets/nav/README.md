# 底部导航图标

五个原生 SVG：小屋、伙伴、专注、装扮、我的。保留原来的入口含义，使用几何直线、圆弧与圆形替代低分辨率位图。

统一 `viewBox="0 0 32 32"`、圆形端点与圆形连接点，普通图标线宽 2–2.1，蓝色专注图标线宽 1.8。绘制内容在四周保留至少两个坐标单位的透明边距，避免描边触碰图片边缘。伙伴图标使用重叠圆头和简洁身体，按用户参考保持简洁。底栏没有底线，中央按钮没有边线阴影。

页面以五列等宽网格排列。普通图标 32 × 32，中央专注图标 44 × 44，置于 64 × 64 的圆形按钮中；按钮比导航上沿高约八像素，并保留底部安全区。
