# 猫咪面部补色第二版

保留六列三排共18种原始表情。所有眉毛和鼻子填暖棕，保留黑色轮廓；睁眼部位按列填虹膜色。闭眼弧线、叉眼、眯眼、怒目和睡眼保持原来的表情。

| pet | 名字 | 原稿列 | 睁眼颜色 |
| --- | --- | --- | --- |
| 0 | 辣椒 | 三花猫 | 琥珀黄棕；第二排左侧星眼为亮黄 |
| 1 | 奶球 | 白猫 | 蓝色；第二排泪痕保持奶白 |

| 5 | 团子 | 橘猫 | 蓝色 |

`cat-{pet}-{expr}.png` 与 `.svg` 为可直接使用的透明资源。`expr` 0/1/2 对应原稿第一/二/三排。SVG 内嵌同名PNG，不是重新绘制的矢量。每帧统一288×288画布和276px脚底基线，表情切换不改变画布。

2026-10-18 使用内置 `image_gen` 对 `assets/cats-v1/atlas.png` 进行局部图像编辑。第一次补面部颜色后，第二次修正布丁后两排的棕眼及奶球白色泪痕，第三次补齐辣椒第三排的小鼻子。全部提示词保存在 `sources/coloring-prompt.txt` 与 `sources/nose-correction-prompt.txt`；前两轮结果保存在 `sources/first-edit.png`、`sources/second-edit.png`，最终工具原始输出为 `atlas.png`。原稿和第一版资源仍完整保存在 `assets/cats-v1/`，未覆盖。生成式局部编辑保留原构图和线条风格，但不承诺所有未修改区域逐像素相等。

`scripts/prepare-cat-colors.cjs` 只切分连通图像、对齐、保护封闭白色内部及导出资源，不绘制或人工补色。`manifest.json` 记录每帧边界、透明修复数和文件摘要。`preview.png` 为透明总览，`preview-cream.png` 为浅底检查图。透明修复只保护被黑线封闭的内部空洞，外部与脚间缝隙保持透明。

验证入口：`tests/cat-art.cjs` 检查18帧真实透明、内部不漏空、共同尺寸和基线；`tests/cat-face-colors.cjs` 在独立人工核对的鼻、眉、眼区域检查实际像素色相，同时检查闭眼与白泪痕。没有用摘要替代颜色验证。
