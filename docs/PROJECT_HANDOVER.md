## 1. 项目定位与运行

核心叙事：用户坐下来陪小动物吃饭，完成一段专注。保持暖米色插画、橙色圆角按钮与温柔文案。

当前入口为根目录 `current_project.html`，用 Chrome 或 Edge 直接打开即可。请保留旁边的 `assets/` 文件夹，复制项目时一并复制。没有构建、安装或恢复依赖步骤。

## 2. 选菜的完整流程

1. 进入专注准备页，点击「切换食材」，放大饭桌，隐藏专注计时与暂停操作。
2. 三个盘子旁各有「换菜」按钮。点击后弹出九宫格菜单。
3. 空盘子、小鱼干、奶块、鸡肉条可选；奶冻、肉罐头、月饼、粽子、小蛋糕显示灰色。点击灰色项只提示「您暂时没有拥有这个食材，还不能选择哦」，不会修改选择。
4. 点击菜品只改变菜单候选。点击「确定，放进这个盘子」才将其写入当前盘子的草稿。空盘子是有效选择，可用于清空某一盘。
5. 下方「确定，摆好这盘菜」随时可以保存，无需逐一确认三盘。只换其中一盘就能保存，其他盘子保留原样；没有修改时确认也不会改变菜品。最终确认才替换正式菜品、保存到本地并缩小饭桌。
6. 菜品在缩小页面、开始专注、暂停及结束后继续显示。刷新会读取上次最终确认的数据。
7. 菜单「取消」丢弃当前菜单候选；饭桌「取消」丢弃整次草稿，恢复原菜品。按 Escape 先关闭菜单，再取消整次选菜。

状态职责：`tempPickIdx` 为当前菜单候选；`draftFoodIdx` 为整顿饭的草稿；`plateConfirmed` 表示每盘是否确认；`plateFoodIdx` 为正式菜品。三盘均为空的初始值是 `[0,0,0]`。旧键 `qingpeiban-meal` 仅用于迁移游客数据，新保存进入当前账号快照。

饭桌原图尺寸为 1344 × 2912。背景、宠物、菜品和换菜按钮都置于 `focus-world` 内，使用同一坐标系；普通预览按 cover 裁切，选菜放大时按 contain 展示整张饭桌，避免横屏丢失盘子。由 ResizeObserver 跟随容器变化更新尺寸。

## 3. 主角与首页互动

「选主角」打开从左侧滑出的面板。列表每次打开时从 `allPets()` 读取，并通过 `petUnlocked()` 过滤；包含六只小狗、六只猫、蜥蜴/蛇、自由画作和捏脸伙伴（鱼已退役）。小豆品种为柯基。六猫在旧三位额外伙伴后追加，顺序为耳朵（三花）、年糕（白）、煤球（黑）、芝麻（奶牛）、布丁（暹罗）、团子（橘），均可出场、装扮及参与互动。后续按现有数据注册方式加入的伙伴会自动进入列表。新增画作统一通过 `addDrawnPet()` 注册；该入口迁移后方捏脸伙伴的主角、装扮、颜色、出场名单、专注历史和好感度索引。点击后同步饭桌与首页，设为常驻主角。专注中不能更换主角。

装扮页面横向主角列表保留 ID `pet-pick`；主角抽屉使用独立 ID `companion-picker`，两者不再冲突。

首页保留主宠与三个配角的原始站位及双击操作。`PetRoom.cadence` 为每只角色分别安排4–7秒的小步、6–9秒的主角轻移、6.5–10秒的相遇机会；随机触发概率分别为0.7/0.72/0.95，不会每轮同时移动或说话。总览使用独立同范围时钟。配角之间可两人/三人会面（三人约45%），约24%的首页会面改为一位配角靠近主角说短句。在猫架与地面之间交替选择会面区，沿梯子中间点行进；基础单程约4.2秒，各位错开约0–1.6秒起步，并使用不同速度和步频，交谈约3.6秒后归位。即使摆了玩具也仍会上猫架；地面行程随机接近一件玩具，包括拖到右边缘的物件。

主角保留中央站位，在±18px范围左右轻走；配角原位小步约5–9px，出发和返回各约1.45秒，行走时身体上下轻抖。招呼配角时主角保持110px大小与当前身份。对话参考桌面最初原型HTML里的「汪！」「蹭蹭你！」「想要零食！」「陪我玩！」以及「蹭蹭/抢玩具/一起看窗外」等短句，按性格排序且允许新角色自定义；猫的汪声替换为喵，其他物种也适配。到家优先角色原line，限制12字。待机小步不强制说话，并与触摸/会面互斥；换主角、换页和换账号清理旧时钟、路径、主角偏移与物件动画。

每段行走独立以 38% 概率翻转，左右行走都可能保留原朝向；身体和装扮上下起伏 2 像素，气泡文字不翻转。每只分别按自身性格说话，拌嘴后会和好，内置文案最多 12 字、通常 2–8 字。关闭页面、切场景或切换账号会取消旧路径和物件动画；系统减少动态效果时保留近距离互动文案而不行走。原 `PetInteractions.encounter()` 小幅两人靠近 API 仍兼容，自动小屋行程改用 `PetRoom`。

配角池同样从 `allPets()` 与 `petUnlocked()` 读取，并遵守出场名单。新增角色可用 `trait` 或 `personality` 指定性格，也可提供 `reactions` 自定义内容；复用同一双击、待机与两两互动流程。没有新增三颗互动按钮、长按或粒子；主宠保留 Enter/空格反馈。

鱼角色与鱼缸已从主页、总览、图鉴、选角、衣橱和互动移除。旧ID8仅保留不可见占位，其他猫ID9–14及创作伙伴ID15起不重排；旧鱼选择回落到小豆，旧捏脸鱼标记退役，出场名单移除鱼。旧专注记录、鱼币及历史装扮仍保存，读取/保存/刷新/切账号均执行相同归一化。旧鱼素材只作为档案保留，不再加载。

场景总览读取首页当前场景图像，客厅跟随已选择的时间与天气，过年门外跟随夜间滤镜；通过场景按钮或首页左右滑动切换时保持同步。初始化同步默认选中的中午晴天背景。总览与首页使用独立的宠物互动列表；关闭总览清理其互动定时器。

图鉴核心为十二位伙伴：小狗六位两排三列，小猫六位两排三列，额外物种和创作伙伴单列在后。顶部十二位伙伴合照、出场名单和详情使用真实素材大头头像，下方六狗/六猫角色卡改为完整全身原稿；小狗通过`DOG_HEAD_CROPS`与`renderDogPortrait()`保留完整耳朵、去掉身体与尾部，小猫裁取同套立绘头部。详情按ID选择，避免按显示名选择造成身份混淆。

未解锁伙伴显示灰度原头像，点击展示获取方式；已拥有权益保留。领取规则：奶糖签到2天、饭团/煤球3天、布丁5天；黑豆、辣椒、耳朵、芝麻、团子各100鱼币，酷盖200鱼币；小豆和年糕可免费领取。签到按本地不同访问日累计，跨午夜继续使用也幂等登记当天，不重复计数；兑换一次保存拥有状态和余额，失败回滚，重复领取不再扣费。全部选择入口校验拥有状态。

底部 TabBar 使用五列等宽网格与本地矢量图标，线条和圆弧规整，端点及连接处圆润，绘制内容四周至少保留两个坐标单位。普通图标 32 × 32；中央闹钟 48 × 48，位于 64 × 64 的圆形按钮中，比导航上沿高约八像素。底部保留安全区。

中央蓝色闹钟增加圆形白色填充，透明度 0.56。

## 5. 专注与音频

「我的」中添加的自定义任务保存在当前本地账号的快照中，旧键 `qingpeiban-tasks` 仅作为游客迁移输入。专注准备页「今天要完成什么？」的输入框点击后展开已有未完成任务，选择后填入输入框并同步到开始专注后的任务标签；也可直接输入临时任务。菜单随窗口空间向上或向下展开，避免被底部导航遮挡。点击外部或按 Escape 关闭，ArrowDown 可进入候选列表。

开始专注时先显示完整设定时长，一秒后再递减。自然完成和主动结束共用清理入口，清理专注、暂停和离开倒计时，恢复选择按钮及页面布局。实际专注不足三分钟不计入累计时长；提前结束时只把实际分钟计入 PK。成功好感奖励按模式为40/25/10/10，所有伙伴（含新猫、其他物种及创作角色）均按自己的ID累加，未初始化值从0开始。

暂停保留既有的一分钟宽限：宽限内专注计时继续，过后暂停计时；继续或结束都会清理暂停定时器。专注期间拦截导航返回与重新设置入口。

开始专注及暂停时隐藏按钮下方的对话气泡，避免挡住桌面；结束后恢复准备/完成提示。暂停/结束按钮固定在底部导航上方，避免舞台高度展开后被底栏覆盖。

背景音乐仍使用用户提供的 Buddy 链接，点击后尝试播放，约两秒渐入到音量 0.25。关闭音乐会停止播放并清理渐入定时器，后续点击不会自动重新开启。加载或自动播放失败不会引发未捕获异常。

按钮气泡声使用原生 Web Audio 播放本地短 PCM 缓冲，离线可用：底栏是较低的双气泡，早中晚/晴雨雪是较高且更短的气泡，其余按钮更轻。波形有柔和起止、28ms 连点去重。音乐和音效独立播放，点击时音乐短暂压到最多 0.14，约 250ms 后恢复之前音量，不暂停音乐；关闭音乐或切账号后不会被延迟回调重新打开。按钮音效开关控制所有层级，`buttonAudio` 留作后续真实素材替换入口。

当前波波声为短弹性共鸣，导航132ms双波、天气92ms单波、小按钮62ms轻波；在柔和包络上略提音高并加入很短的轻泛音，提高通透感。三份实际WAV试听位于 `assets/audio-preview/`，波形测试验证音高、起止、强弱和高频能量。

## 12. 动物PK、声音设置与边界

好友页把PK放到排行前，身份图使用陪饭伙伴；开始对局时记录该伙伴，同一局保持出场身份。对手有独立陪饭动物选择，双方支持玩耍、拌嘴后和好、一起吃饭，短句按性格选择，减少动态效果时保留文案。当前没有在线服务，明确显示“本地体验”，不发放假在线PK奖励。对局日期固定保存，跨日会结算并允许开始新一天，旧账号缺日补齐；次日尚未开始时预览当前伙伴。真实玩家伙伴、专注分钟及可信结算需后续服务器接入。

设置拆分背景音乐、按钮音效、场景音乐及专注音景。雨天轻雨、雪天微风随客厅天气切换，场景音乐有独立开关和音量，不受按钮音效开关影响。专注页直接选择轻钢琴、窗边雨声、安静图书馆、微风草地、夜晚虫鸣，或不叠加专注音景；支持20秒试听、试听停止、音量选择。专注时暂停原背景曲、按所选音景播放，选择不叠加音景时仅保留已开启的场景音乐；结束后恢复背景曲设置，场景音乐仍按独立开关播放。暂停、离开试听页、返回、账号切换、页面隐藏正确清理/暂停。按钮波波声短暂压低音景，避免遮盖反馈。声音为本地原创合成循环，无外部音频依赖，不使用其他软件的音乐。

设置单例、键盘焦点循环与关闭恢复；账号隐私页说明本地数据和相册用途，不再误跳到音乐开关。完整检查和解决方案见docs/research/2026-10-19-settings-review.md。新增专项测试为companion-progress、community-browser、pet-pk、soundscapes；截图见docs/research/2026-10-19-community-*.png。

## 15. 单件穿戴微调与独立创作

装扮先套用默认位置，再可进入“微调位置”选择单件拖动；手机双指缩放，电脑使用百分比滑杆（50%–180%），可恢复这件默认。坐标用角色框百分比保存，首页/专注按自身尺寸显示。同衣服及颜色一起点“确定装扮”才保存，不因普通点击、拖动结束或后台自动保存而泄露草稿；未拥有服装仍须解锁。确认失败回滚已保存设置、保留重试草稿。

每账号快照新增outfitTransforms，按真实角色ID和服装名保存。桥接层保留启动时字段，调整模块初始化读取它，避免异步加载丢存档。换账号清理手势，插入画作时随既有自捏ID一起迁移；自捏使用shapeSource的衣服锚点、不是coatSource。说明与验证见docs/research/2026-10-19-outfit-micro-adjust.md。

自捏三阶段保留无色轮廓草稿，性格决定耳尾姿态及表情，最后选限定品种毛色/花纹。耳尾采用小幅、根部连续的局部形变，不切走整块额头；日常表情仅在脸内变。毛色替换保留源alpha、描边、眼鼻眉、封闭白眼高光；颜色不会更换轮廓。file协议以已内嵌的36原图帧避免Canvas跨源污染，ready后自动补全账号恢复的姿态和配色，不用等下一次互动。原稿与旧自创继续保留。

## 16. 家具承托与自动情绪互动

HouseEditor.getAnchors为原型及三款家具提供承托面与出入口，左右配角按实际脚底落在对应猫架/座面。闲步受承托范围约束，往返经梯子、座沿与地面，避免穿墙；沙发近侧扶手保留前景遮挡。自捏伙伴按所选shapeSource计算脚底，配色不影响落点。原型款可逐槽选择，只改变该槽草稿，确认才同步；不再提供全屏布置按钮。说明见docs/research/2026-10-19-furniture-pet-support.md。
